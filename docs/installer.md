# NimehOS Installer

نصب‌کننده‌ی گرافیکی بسته‌ها برای NimehOS — مثل Windows Installer.

## پشتیبانی
- `.flatpak` — نصب در فضای کاربر (بدون sudo)
- `.AppImage` — کپی به `~/.local/bin/`
- `.deb` — نصب سیستمی (نیاز به sudo)
- `.rpm` — نصب سیستمی (نیاز به sudo)

## نصب
```bash
~/NimehOS/scripts/install-installer.sh
```

## استفاده
روی هر فایل بسته دابل‌کلیک کن — پنجره‌ی نصب باز می‌شه.

## خط فرمان
```bash
nimehos-installer package.flatpak
```
